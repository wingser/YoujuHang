游聚挂机控制台

挂机功能
  • 每日签到：登录后自动完成当日签到
  • 在线时长保持：自动维持在线状态，持续累计在线时长与经验
  • 任务奖励自动领取：在线时长、连续签到（7/14/21 天）、日常达标等奖励到达即可自动领取
  • 月度礼包：每月 1-7 日自动领取微信绑定礼包
  • 经验头像：每天检查一次，保证佩戴经验加成最高（如 1.4 倍）且未过期的头像—— 已佩戴有效加成头像时不做任何操作，仅在未佩戴 / 无加成 / 已过期时自动改戴； 当前头像与剩余天数显示在「基础信息」列；加成型头像多绑定具体页游角色， 账号在该页游无角色或等级不足时会改戴失败，鼠标悬停头像行可看原因
  • 被踢自动重登：会话被其他设备顶下线后，自动检测账号离线状态并重新登录
  • 多账号并行：一台电脑可同时挂多个账号，设备标识自动分配，无需手动配置
战队任务（自动挂机相关）
  • 战队任务仅对已加入战队的账号自动开启；未加入战队的账号默认不开启对应任务
  • 战盟挂机：自动进入 8bit 音乐挂机区保持在线，累计战队在线任务时长（3 小时奖励达成后自动退出）
  • 战队贡献捐献：每日自动捐献贡献度（默认目标 3000，贡献度余额低于 3000 时暂停捐献）
