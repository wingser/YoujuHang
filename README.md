# 游聚挂机（YoujuHang）

多账号自动在线挂机工具。基于协议逆向实现的纯协议客户端，无需启动游戏，单进程即可托管多个账号持续在线，自动完成每日签到、任务奖励领取、商城礼包、战队捐献等日常操作。

提供 Web 控制台与系统托盘，账号启停、状态监控、日志查看均在浏览器中完成。

> 支持 Windows 7（x86/x64）及 Windows 10/11。

---

## 功能

### 账号与在线

- **多账号并发**：单进程同时托管任意数量账号，每个账号独立登录、独立心跳、独立业务循环，互不阻塞。
- **24 小时在线**：按设定周期刷新在线状态（含随机抖动，规避风控），持续累计在线时长与经验。
- **单账号启停**：可单独启动/停止任一账号，也可一键全部启停，无需重启程序。

### 自动化日常

- **每日签到**：每天自动签到，领取签到奖励并累计签到天数。
- **任务奖励自动领取**：自动领取所有已达标奖励，包括在线时长档位（10/30/60/120 分钟等）、连续签到 7/14/21 天、日常达标任务。支持为单个账号配置附加任务 ID。
- **商城礼包（月度）**：每月 1-7 日自动领取微信绑定礼包，**每月仅一次**。
  领取后本月一直显示"已完成"，下个月自动恢复可领；其余时间（8 日之后）显示"未到期"且不请求。
  领取状态持久化在 `mall_state.json`，程序重启不会退回"未领取"、也不会重复请求。
  未绑定微信的账号显示"不可领取"，本月内不再尝试。
- **经验头像（保持最高加成）**：每天检查一次，保证账号佩戴着**经验加成最高**
  （实测有 1.1/1.2/1.4 等档位）且未过期的头像：

  - 已佩戴有效的加成头像（剩余 >1 天）→ **不做任何操作**（重启、重登都不会重复佩戴）；
  - 未佩戴 / 戴的是无加成头像 / 已过期 / **剩余不足 1 天** → 自动改戴最优加成头像，
    无需手动续期或更换（提前 1 天换是为了避免到期后出现加成空档，
    可用 `avatar_renew_before_days` 调整，0 = 只在过期后才换）。
    注意：**提前更换时**，只有当别的头像「有效期更长且加成不低于当前」才会换；
    若候选加成更低（如用 1.2 倍换掉 1.4 倍），则保持不动，等当前头像过期后再换。

  当前头像与剩余天数显示在「基础信息」列。
  加成型头像多绑定具体页游角色（如「维京传奇 144服 420级」），账号在该页游无角色或等级不足时会
  改戴失败，日志记录服务端返回的原因，不影响挂机。用 `avatar_enabled: false` 关闭。
  协议与已知坑见 [docs/avatar_api.md](docs/avatar_api.md)。
- **战队任务**（需已加入战队）：
  - **战盟挂机**：自动进入 8bit 音乐挂机区房间保持在线，累计战队在线时长，达成 3 小时目标后自动退出。
  - **战队捐献**：每日自动捐献贡献度至设定目标，余额低于下限时跳过。
  - 未加入战队的账号自动跳过全部战队相关功能。

### 挂机有效期（可选）

可为每个账号设定挂机天数，到期后自动停止挂机：

- **新增账号**时填「挂机天数」：填 3 表示从**今天起 3 天**（今天、明天、后天、第 3 天都能挂机，第 4 天起过期）。
  **留空或填 0 = 长期挂机，永不过期**。
- **编辑账号**时填「增加天数」，这是**增减量**（可填负数）。基数取「原到期日」还是「今天」，取决于账号当前**是否已过期**（2026-09-02 调整）：

  | 账号状态 | 输入 | 结果 |
  |---|---|---|
  | 未过期（如 2026-09-03） | `30` | 2026-10-03（在原到期日上延长） |
  | 未过期 | `-7` | 2026-08-27（在原到期日上缩短） |
  | 未过期 | 留空 / `0` | 保持不变 |
  | **已过期**（如 2026-08-26） | `30` | 今天 +30 —— **从今天起算** |
  | 已过期 | `-7` | 仍在原到期日上向前减 |
  | 已过期 | `0` | **改为今天**（今天还能挂机，明天起过期） |
  | 长期（空） | `30` | 今天 +30（给长期账号设定期限） |
  | 长期（空） | 留空 / `0` / 负数 | 保持长期不变 |

  > 已过期账号填正数时改以**今天**为基数：若仍从过期日累加，加完还是过去日期、账号依旧不能用。
  > 例：一周前过期的账号填 `1`，到期日就是明天。
- 天数**只接受整数**（填 3.5 会提示错误）；范围 ±3650 天。
- 账号列表第一列会显示有效期，例如 `有效期至 2026-09-03（剩 3 天）`；剩余 ≤3 天时橙色提醒，已过期红色显示。
- **到期行为**：未过期时随「全部启动」和程序启动一起运行；到期当天 23:59 前仍可挂机，次日自动停止。
- **已过期的账号**：不会被自动启动；手动点「启动」会提示确认，确认后仍可强制启动。

### 重复账号

新增账号时**不允许重名**（含仅大小写不同）：

- 后端在 `AddAccount` 中按**忽略大小写**做重名校验——`abc` 与 `ABC` 视为同一账号，后者会被拒绝，提示「账号 xxx 已存在，不能重复添加」。
- 之所以连大小写变体也拦掉：服务端通常会把两者识别成同一用户，若同时挂机，两个账号会互相顶下线，表现为反复掉线重连。
- 前端在提交前也会即时查重并给出明确提示；服务端仍是权威校验（最终兜底）。
- 删除账号后可重新添加同名账号。
- 若 `accounts.yaml` 被手工编辑出重名账号，程序启动时会**告警**（后者覆盖前者），请按提示修正配置。

### 启动后一直"登录中"

若某个账号启动后长时间停在「登录中」，通常是**同一账号出现了并发登录**：程序内部已做防护——
停止后再启动时，新任务会先等待旧任务真正退出再登录，登录成功后若发现自己已被取消也会立即退出，
不再顶掉新会话。遇到该状态时**停止后稍等几秒再启动**即可。

程序还会把登录阶段的等待控制在半分钟内（此前网关无响应时可假死近 3 分钟且无任何日志）。

### 崩溃自动重启（守护进程）

发布目录中的 `youjuhang-guard.exe` 是守护进程，**主程序启动成功后会自动拉起它**：

- 每分钟检查一次主程序存活心跳（`run_state.json`）
- 检测到**崩溃**（进程消失）→ 立即重新拉起，恢复所有账号挂机
- 检测到**假死**（进程在但心跳长时间不更新）→ 连续两次确认后强制重启
- 主程序**正常退出**时守护进程自动结束，不打扰用户

已完成的任务**不会重复执行**：签到/任务领取以服务器状态为准（已领的 `f5≠0` 不再重复领取），
当日捐献量持久化在 `contribute_state.json`，重启后不会重复捐献。

> **守护进程是可选组件**：目录里没有它时，主程序照常独立运行，仅不具备崩溃自动重启能力。
> 主程序也不会因为它启动失败（如 32 位系统运行 64 位守护进程）而退出。

守护进程日志：`logs\guard.log`。

> 注意：若整机重启（系统更新、断电），守护进程同样会退出，需配合**开机自启/计划任务**才能恢复。

### 进程异常退出的排查

若发现程序进程消失、日志里没有「youjuhang 退出」，说明是**异常终止**（崩溃或被强杀）。

程序会在运行目录维护 `run_state.json` 存活标记（每分钟刷新，优雅退出时删除）。
下次启动若发现该文件残留，会在日志与 `startup_error.txt` 中报告**上次启动时间、最后存活时刻、已停止时长**。

排查方法：把「最后存活时刻」与 Windows 事件日志的 **6006 / 6008 / 1074** 对照——

- 两者紧邻 → 系统关机/重启或 Windows 自动更新导致（外部原因），建议配置**开机自启 / 计划任务**
- 系统当时一直在运行 → 才按程序崩溃排查，请把 `startup_error.txt` 与 `logs/` 一并提供

查看事件日志示例（管理员 PowerShell）：

```powershell
Get-EventLog -LogName System -InstanceId 6006,6008,1074 -After (Get-Date).AddDays(-3) |
  Select-Object TimeGenerated, InstanceId, Message
```

### 被踢处理

账号被其他设备登录顶下线时，程序**不会抢占用户**。恢复分两级，均可全自动完成：

**一级：在线侦查**（还有其他账号在线时）

- 从**当前挂机中的账号里随机选一个**当侦查账号（不再固定用第一个，避免探测请求全压在同一账号上）。
- 每 60 秒用侦查账号只读查询目标账号的在线状态：在线则继续等待（说明你正在玩），离线则自动重登恢复挂机。
- 侦查账号自身失效时，会轮换到其他在线账号，不会卡在同一个上反复失败。

**二级：兜底探测**（所有账号都掉线，如服务器维护、整机断网）

- 每 **10 分钟**从账号列表中**随机选一个**账号尝试登录。
- 登录失败 → 服务器仍不可用，等下一轮；登录成功 → 说明服务器已恢复，立即用它侦查目标账号，离线则恢复挂机。
- 选择候选时**优先挑未被用户占用的账号**（`offline`/`stopped`/`login_fail`），只有在没有其他候选时才会用处于「等待恢复」的账号，尽量不顶掉用户。

**设计原则：绝不顶掉正在游戏的用户。**

### 监控与管理

- **实时状态**：账号昵称、等级、总经验、当日经验、游币，以及每日任务/战队任务的逐项完成状态。
- **挂机到期日**：账号名下方显示有效期（如 `有效期至 2026-09-03（剩 3 天）`），临期橙色提醒、已过期红色显示。
- **Web 控制台**：浏览器访问，支持账号增删改、启停、日志查看。
- **独立日志**：每个账号单独日志文件，便于按账号排查。

### 其他

- **系统托盘常驻**：后台运行无控制台窗口，托盘菜单可打开控制台或退出。
- **配置热更新**：在控制台新增/编辑/删除账号会即时持久化到配置文件。

## 快速开始

### 1. 获取程序

- **直接使用**：`server/dist/` 目录下已有构建好的程序
  - `youjuhang-win64.exe` — 64 位
  - `youjuhang-win32.exe` — 32 位（Win7 x86/x64 均可运行）
  - `youjuhang-guard.exe` — 守护进程（可选，主程序会自动拉起；缺失时主程序独立运行）
- **自行构建**：运行 `server/build.bat`（需 Go 1.21 工具链，详见[技术文档](docs/technical.md)）

> **从仓库克隆后没有 `dist/`**：构建产物与抓包素材（`captures/`，约 12.8GB）都不入库，
> 克隆后请先运行 `server/build.bat` 自行构建。完整入库范围见[技术文档 6.4 节](docs/technical.md)。

### 2. 配置账号

编辑程序同目录的 `accounts.yaml`，或启动后通过 Web 控制台添加：

```yaml
login_addr: gamelogin3.gotvg.com:18000
web_addr: 127.0.0.1:29090   # 控制台监听地址（仅本机访问）
refresh_minutes: 10         # 在线刷新间隔（分钟）

check_in_enabled: true      # 每日签到
auto_claim: true            # 自动领取任务奖励
mall_enabled: true          # 商城礼包（每月 1-7 日）
avatar_enabled: true        # 保持佩戴最高经验加成头像
room_hang_enabled: true     # 战盟房间挂机
contribute_enabled: true    # 战队捐献
contribute_daily: 3000      # 每日捐献目标
contribute_min_balance: 3000  # 余额低于此值不捐
contribute_step: 1000       # 单次捐献量

accounts:
  - name: youname
    password: "xxxxx"
    mac: "2E-4A-62-F7-D7-F3"   # 硬件信息上报
    enabled: true
    expire_date: "2026-09-03"  # 可选：挂机到期日，留空/删除此行=长期挂机
```

> `expire_date` 一般不用手写，在控制台新增/编辑账号时填「天数」即可自动生成。
> `mac` 也可省略——首次启动会自动生成并写回配置（多账号各自独立，无需手工分配）。

### 3. 运行

双击 `youjuhang-win64.exe` 即可，程序会自动打开 Web 控制台。

命令行参数：

```
youjuhang-win64.exe [-config accounts.yaml] [-web 127.0.0.1:29090] [-console]
```

| 参数 | 说明 |
|---|---|
| `-config` | 指定配置文件路径 |
| `-web` | 自定义控制台地址（优先级高于配置文件） |
| `-console` | 日志同时输出到控制台（调试用） |
| `-no-browser` | 启动时不自动打开浏览器（守护进程重启时会自动加上，避免反复弹窗） |

## Web 控制台

默认 `http://127.0.0.1:29090`。

- **账号列表**：实时状态、昵称、等级、经验、游币、每日任务与战队任务的完成进度
- **账号操作**：启动 / 停止 / 编辑 / 删除，顶部支持全部启停
- **日志**：点击账号的「日志」按钮查看其独立运行日志

**安全提示**：控制台默认绑定 `127.0.0.1`，仅本机可访问。**请勿配置为 `0.0.0.0` 或局域网 IP**，否则会暴露到网络。

## 状态说明

| 状态 | 含义 |
|---|---|
| 在线 | 正常运行，持续保持在线并执行日常任务 |
| 未运行 | 已配置但未启动 |
| 已停止 | 手动停止 |
| 等待离线 | 账号被其他设备登录，挂机已暂停。有其他账号在线时会自动侦查，检测到您下线后自动恢复；若全部账号都掉线（如服务器维护），则每 10 分钟探测一次服务器，恢复后自动重连 |
| 登录失败 | 账号密码错误或网络异常，自动重试中 |

```

商城礼包领取成功 pkg=1
检测到账号已加入战队，开启战队任务（挂机/捐献）

```

## 注意事项

- 配置文件包含**明文密码**，请妥善保管，勿提交到公开仓库。
- 被踢后优先等待用户游戏结束再恢复挂机，避免影响正常游戏体验。
- 本工具用于个人账号自动挂机，请遵守平台使用规则。
